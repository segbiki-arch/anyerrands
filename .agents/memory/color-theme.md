# AnyErrands Color Theme

Yellow and black — modern, premium.

- **Primary**: hsl(47 100% 50%) — bold yellow
- **Primary foreground**: hsl(0 0% 5%) — BLACK (not white; yellow needs dark text)
- **Sidebar**: hsl(0 0% 5%) — near-black
- **Background**: hsl(0 0% 98%) — clean white
- **Active nav item**: bg-primary/20 + text-primary + border-l-2 border-primary

**Why:** "Fine yellow and black" — luxury/bold. Yellow buttons with white text look washed out; must use black foreground on yellow.
